# internal/v8

Pre-built V8 assets. Generated by `scripts/fetch-v8.sh` and `scripts/build-v8.sh` - do not edit directly.

## Updating V8

1. Find the Chrome stable version at https://chromiumdash.appspot.com/releases?platform=Linux
2. Look up the V8 commit in the Chromium DEPS at that tag:
   `https://chromium.googlesource.com/chromium/src/+/refs/tags/<version>/DEPS`
   Search for `v8_revision`; that SHA is your commit.
3. Update `SOURCE_COMMIT` with the SHA.
4. Rebuild:

```bash
make fetch
make build              # current host (macOS arm64)
make build-linux-x64    # requires Docker
make build-linux-arm64  # requires Docker
```

5. Commit `internal/v8/`.
